# Contributing

Thanks for wanting to help.

1. Read and agree to the [Contributor License Agreement](CLA.md). Add a line to your first pull request saying: "I have read the CLA and agree to its terms."
2. Run `npm test` and `npm run build` before opening a pull request.
3. Examples must use made-up systems only. Never contribute material from real programs, controlled unclassified information (CUI), or anything export-controlled.
